# 과목 선택 연습실

고교학점제 과목 선택 딜레마를 직접 경험하고, 서울대·동국대 학생부종합전형 가이드북과 서울대 아로리 '나도 입학사정관' 합격자 기록을 근거로 "효율만 따진 과목 선택"의 한계를 확인하는 연습 페이지입니다.

## 구성
- ① 연습하기: 진로 4유형(공학 / 인공지능·데이터 / 경영·경제 / 진로 미정) × 딜레마 3개 + 공통 딜레마 2개(등급 없는 과목, 출결)
- ② 증명 노트: 전제 5개 → 결론 (5등급제 1등급 자리 계산기 포함)
- ③ 근거 자료실: 서울대·동국대 가이드북 쪽수별 근거, 아로리 합격자 기록 4건, 성균관대 설명회 요약, 교육부 2028 대입 개편안
- ④ 출결 이야기: 유튜브 영상, 성균관대 출결 데이터(요약자료 13쪽), 동국대 49쪽
- 교사용 안내: 50분 수업 흐름, 지도 유의점

## 수정 방법
- 유튜브 영상 요약: `index.html`에서 `VIDEO_SUMMARY` 배열에 한 줄씩 입력하면 ④ 출결 이야기에 표시됩니다.
- 딜레마 내용: `PERSONAS`(진로별)와 `COMMON`(공통) 안의 `situation`, `facts`, `options`를 고칩니다.
- 근거 문구: `EV` 객체의 각 항목(`page`, `quote`, `body`)을 고칩니다.

- 동국대학교, 「2027 동국대학교 학생부위주전형 가이드북」
