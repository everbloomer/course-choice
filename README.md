# 내 학생부 톺아보기

학교생활기록부 항목별로 대학이 무엇을 어떻게 읽는지 직접 확인하는 학생용 연습 페이지입니다. 서울대·동국대 학생부종합전형 가이드북, 서울대 아로리 '나도 입학사정관', 경희대·중앙대·성균관대 입학처 자료를 근거로 합니다.

만든이: 행신고등학교 3학년부장 정진

## 구성
1. 교과학습발달상황(숫자)
   - 과목 선택 연습: 진로 4유형 × 딜레마 3개 + 공통 딜레마 1개, 선택 이유 쓰기, 결과 리포트
   - 성적표 읽기: 교과학습발달상황 표 비교 8개
2. 교과학습발달상황(세부능력 및 특기사항): 동국대 가이드북 사례 비교 2쌍
3. 출결 상황: 출결 딜레마 4개 + 대학별 입장(경희대 영상·중앙대 동점자 개근·성균관대 출결 데이터·동국대·교육부 규정)
4. 창의적 체험활동: 자율·동아리·봉사·진로 기록 비교 4쌍
5. 행동특성 및 종합의견: 기록 비교 2쌍
6. 근거자료: 증명 노트, 근거 자료실
7. 교사용 안내

## 수정 방법 (index.html)
- 과목 선택 딜레마: `PERSONAS`(진로별), `COMMON`(공통)
- 성적표 비교: `COMPARE`
- 출결 딜레마: `ATT`
- 세특·창체·행특 기록 비교: `RECS.seteuk`, `RECS.chang`, `RECS.haeng`
- 근거 문구: `EV` 객체(`page`, `quote`, `body`, `src`)
